## What I'm building now

- **[Credentia](https://github.com/jenish1345/Credentia)** — issue, share and verify credentials, with a Monad testnet deployment and an Envio indexer.
- **[Credentia-Local](https://github.com/jenish1345/Credentia-Local)** — *prove eligibility once.* Students upload a document one time; a trusted local issuer confirms it; organizers only see **Eligible / Not eligible / Needs review**. Next.js, Prisma, accessibility-first.
